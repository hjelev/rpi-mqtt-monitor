Home Assistant Integration

When discovery_messages = True (the default), a new MQTT device is created in Home Assistant automatically — no configuration.yaml edits required. Just add it to a dashboard.

Home Assistant API

To bypass MQTT and push directly to the HA REST API, use the --hass_api flag and configure hass_host and hass_token in config.py.

Wake on LAN

Run rpi-mqtt-monitor --hass_wake to print the YAML snippet for a Home Assistant Wake-on-LAN switch preconfigured with your device's MAC address and IP.

Sleep / wake state

For machines that suspend and resume, set sleep_state = True (or answer yes in install.sh). The service watches systemd-logind over D-Bus and publishes a Sleep State sensor to <prefix>/<host>/sleep_state:

  • Before suspend/hibernate: sleeping is published and status goes to disconnected immediately. A short logind "delay" lock makes sure this goes out before the machine sleeps (capped by InhibitDelayMaxSec, so suspend is never blocked).
  • After resume: the service reconnects, publishes awake and sends fresh readings straight away.

Requires the systemd service (--service) in MQTT mode on a systemd host. Check it is active with systemd-inhibit --list.
